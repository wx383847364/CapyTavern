# 方案与数据

这里放玩法、系统、数值、UI、配表与数据结构的方案。草案和已稳定的稿子都在这一处，用文档开头的「状态」区分，不再另建稳定区副本。

## 放什么

- 玩法、系统、数值、UI 的方案草案与定稿。
- 配表字段设计、数据结构草案。
- 可交互原型、示意图、临时数据。

## 命名与开头

- 文件名：`主题 vX.Y.md`；同主题升级版本另起文件，不覆盖旧版。
- 每份文档开头写清状态：

```text
> 状态：草案 / 评审中 / 已稳定
> 版本：v0.1
> 更新：2026-11-04
> 负责人：酒馆策划
```

## 什么时候算稳定

- 经制作人裁决或验收后，把同一份文档的状态改为「已稳定」，更新日期。
- 在 `doc/长期主文档/主文档索引.md` 的「方案与数据」登记。
- 旧版本文件保留，供追溯，不再回写。

## 不放

- 引擎生成物、导出物、构建产物。
- 大体积截图包、录屏、临时压缩包。
- 密钥、账号、Token。
