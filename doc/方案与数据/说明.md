# 方案与数据（工作区）

这里放还没稳定的方案、数值草稿、原型和配表草案。

## 放什么

- 玩法、系统、数值、UI 的方案草案。
- 配表字段设计、数据结构草案。
- 可交互原型、示意图、临时数据。

## 命名与开头

- 文件名：`主题 vX.Y.md`；同主题升级版本另起文件，不覆盖旧版。
- 每份开头写清状态：

```text
> 状态：草案 / 评审中 / 已稳定
> 版本：v0.1
> 更新：2026-11-04
> 负责人：酒馆策划
```

## 稳定之后

- 经制作人裁决或验收后，复制稳定版到 `doc/长期主文档/方案与数据/`，状态改为「已稳定」。
- 在 `doc/长期主文档/主文档索引.md` 登记。
- 草案原稿保留，供追溯，不再回写。

## 不放

- 引擎生成物、导出物、构建产物。
- 大体积截图包、录屏、临时压缩包。
- 密钥、账号、Token。
