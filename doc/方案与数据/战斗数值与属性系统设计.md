## 2 数值类型与单位

| 类型 | 字段／单位 | 说明 |
| --- | --- | --- |
| 一级属性 | strength / agility / stamina / intellect / spirit，点 | 力量／敏捷／耐力／智力／精神 |
| 输出评级 | precision_rating / critical_rating / haste_rating / mastery_rating / penetration_rating，评级点 | 精准／暴击／急速／专精／穿透；不能把评级点直接当百分比 |
| 防御 | armor / magic_resistance，防护值；evasion_rating，评级点 | 合并魔抗，不拆火冰等学派；回避是质量对抗，不是随机闪避 |
| 派生 | power=P，强度；max_hp，生命；auto_interval，秒 | 同一P用于该角色伤害、治疗和护盾系数；不另造一套治疗强度 |
| 修正 | damage_bonus / healing_bonus / shield_bonus / critical_bonus / auto_frequency_bonus | 比例用小数存储：15%写0.15；+10百分点写+0.10 |
| 状态 | hp / resource / shield_remaining / cooldown_remaining | 当前量、秒；与属性定义分离，不保存派生数值为权威来源 |

所有输入必须有限数（无NaN／Infinity）。定义中的评级、防护、一级属性基础值非负；装备负面效果使用显式修正字段，派生后下限0。非法配置拒绝加载并报字段，不把错误静默变成超强角色。单位距离为米，时间为秒。

内部采用双精度浮点，不逐跳四舍五入；展示生命／伤害为整数，百分比1位小数、间隔2位小数。显示0不代表内部伤害为0，不强制每次至少造成1点伤害。战斗统计累加原始有效量后展示。

## 3 四职业一级属性与等级成长

### 3.1 无装备、无天赋基值

等级L为1至60的整数。下表每格为“1级值／每级增量”，使用线性成长：

`属性(L) = 1级值 + 每级增量 × (L−1)`。

| 职业 | 力量 | 敏捷 | 耐力 | 智力 | 精神 | 职业基础生命 | 基础护甲 | 基础魔抗 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 战士 | 20／3.0 | 8／0.6 | 24／3.4 | 4／0.2 | 6／0.3 | 120／8 | 30／4 | 10／1 |
| 盗贼 | 8／0.6 | 22／3.2 | 18／2.6 | 6／0.3 | 6／0.3 | 100／6 | 18／2.5 | 10／1 |
| 法师 | 4／0.2 | 6／0.3 | 14／2.0 | 24／3.6 | 12／1.0 | 80／5 | 8／1 | 20／2 |
| 牧师 | 5／0.2 | 6／0.3 | 18／2.4 | 18／2.4 | 24／3.0 | 100／6 | 12／1.5 | 20／2 |

职业基础生命是生命公式中的独立基项，不包含耐力生命。基础护甲／魔抗随后加装备和显式修正。一级属性允许小数，不逐级取整。所有五项二级输出评级与回避评级默认0，只有装备／明确效果提供；不额外随等级免费赠送评级。

两专精共享职业成长，专精切换不换基础属性表。牧师以精神为主强度属性，智力为次强度；法师以智力为主、精神为次。力量不顺带赠送暴击，敏捷不免费增加护甲／回避，智力不扩大法力上限，精神不增加战士怒气或盗贼能量恢复。牧师回蓝在150精神处连续转为较低斜率，不改变精神对P的换算。无作用属性在该职业上显示“当前无战斗换算收益”。

### 3.2 派生属性顺序

```text
一级属性 S = max(0, (等级基值 + 装备平值 + 临时平值) × max(0, 1 + 同组百分比之和))
战士 P = max(0, 20 + 装备强度 + 临时强度 + 2×力量 + 0.5×敏捷)
盗贼 P = max(0, 20 + 装备强度 + 临时强度 + 2×敏捷 + 0.5×力量)
法师 P = max(0, 20 + 装备强度 + 临时强度 + 2×智力 + 0.5×精神)
牧师 P = max(0, 20 + 装备强度 + 临时强度 + 2×精神 + 0.5×智力)
若有显式强度百分比：P再乘max(0, 1 + 同组强度百分比之和)，只计算一次
最大生命 = max(1, (职业基础生命(L) + 10×耐力 + 额外生命平值) × max(0, 1+生命百分比之和))
护甲／魔抗 = max(0, (对应职业基础防护(L) + 装备防护 + 临时防护平值) × max(0, 1+对应防护百分比之和))
```

武器的“强度”计入装备强度一次；本版技能统一k×P，不再额外叠加武器DPS×时间。武器攻击动画不决定普攻间隔，普攻间隔以职业配置为准。强化力量和直接强化P是两个不同参数，必须各有来源，不把同一天赋重复写进两处。

升级、装备或增益改变上限时，当前生命设为`min(旧当前生命, 新上限)`，不按比例补血；资源同理。死亡角色不能通过增加耐力复活。下一次出征按原规则满生命、初始化资源和冷却。真实升级事件按成长系统1.0在回酒馆领取经验奖励时发生，战斗中固定加载等级；本稿只提供L到属性的计算。

## 4 评级与暴击

所有评级换算K=1000，1至60级固定，不读取攻击者／目标等级。`r`为已经过平值与百分比修正且下限0的对应评级。

| 派生值 | 公式 | 零评级 | 渐近上限 |
| --- | --- | --- | --- |
| 暴击收益参数c | `0.05 + 0.45×r/(r+1000)` | 5% | 50% |
| 急速h | `0.30×r/(r+1000)` | 0 | 30% |
| 穿透p | `0.35×r/(r+1000)` | 0 | 35% |
| 专精收益m | `a×r/(r+1000)`，a见第6节 | 0 | a |

当前暴击为**稳定折算**：可暴击事件使用`C=1+c×b`，基础额外暴击收益b=0.50；若有明确critical_bonus则`b=clamp(0.50+额外增量,0,1.50)`。本稿不提供普通装备暴伤词条的掉落预算，只预留字段。

例如暴击评级1000：c=27.5%，C=1.1375，表示每次合格事件稳定增加13.75%，不是每次随机27.5%概率打出1.5倍。不显示随机“暴击！”飘字，不产生“本次暴击”事件；天赋4.0的热力、霜指均按节点明确次数触发，与c无关。面板必须写明“暴击收益率／稳定折算”，不能伪装随机触发。

| 事件 | 精准对抗 | 暴击收益 |
| --- | --- | --- |
| 玩家直接伤害普攻、Q/W/E/R直接伤害 | 是 | 是 |
| 玩家直接治疗及牧师友方普攻 | 否 | 是 |
| 持续伤害、持续治疗、火场／冰区跳伤 | 伤害是、治疗否 | 否 |
| 护盾生成、资源恢复 | 否 | 否 |
| 基础戒律Q固定附带治疗 | 否 | 否，不因Q伤害暴击收益放大 |
| 赎罪治疗 | 否 | 否，基础取最终有效伤害后不再乘C |
| 附加固定伤害／治疗（如0.60P） | 伤害是、治疗否 | 默认否 |
| 按最终伤害复制的顺劈等 | 已包含来源结果，不再次对抗 | 不再次乘C |

敌人普通攻击和技能默认C=1，不借用玩家5%基础暴击收益；敌人危险性由公开技能倍率与预警实现。以后新增例外需在技能配置中显式声明，不能给首领暗中暴击。

## 5 精准、防护与穿透

### 5.1 命中质量

```text
q = 1 + 0.25 × (攻击者精准 − 目标回避) / (攻击者精准 + 目标回避 + 1000)
```

q是伤害倍率，趋近0.75至1.25，不是命中概率。双方评级0或相等时q=1。物理和魔法伤害均适用，不存在“法术不需要精准”的隐藏例外。治疗不与友方回避对抗。

有效距离、存活、阵营和配置要求的遮挡检查在付费前完成。没有随机未命中、闪避、招架或格挡掷骰；可见的移动避开地面范围仍可使范围效果无目标。连续质量不能让非法目标强行吃伤害。

### 5.2 防护

```text
p = 0.35 × 穿透评级 / (穿透评级+1000)
F = max(0, 目标对应防护 × (1−p))
M = 1000 / (1000+F)
物理读armor，魔法读magic_resistance
```

同一穿透评级同时用于物理和魔法，无治疗／护盾穿透。不能穿成负防护。当前不采用历史格挡防护附加层、额外魔法学派抗性、护甲减免百分比词条、控制疲劳和隐藏破防；未来新增须升级公式版本。

F=0／500／1000／2000时，M分别为1／2⁄3／1⁄2／1⁄3。穿透评级1000得到17.5%穿透；原1000护甲变825，M=1000/1825≈0.547945，不能误算成减伤率直接减17.5百分点。

技能主动减伤在M之后处理：`A=1−clamp(当前所有适用减伤中的最大值,0,0.60)`。伤害降低类效果（如雷霆余威、麻痹飞刃）归入攻击者输出端的同组净伤害修正，作用于其所有伤害；不额外重复当作目标减伤乘一次。不同施法者的同名伤害降低取最强，异名在该输出组加算，净修正下限−60%。

`m=a×mastery_rating/(mastery_rating+1000)`，合格事件乘一次`1+m`。未列出的事件m=0。

## 7 急速、资源与时钟

```text
普攻频率倍率 = max(0.25, 1+h+同组普攻频率增益之和)
实际普攻间隔 = 职业基础间隔 / 普攻频率倍率
实际公共施法间隔 = max(0.75, 1/(1+h))
盗贼自然能量恢复 = max(0, 8×(1+0.50h) + 天赋等额外每秒能量)
法师自然法力恢复 = max(0, (3+0.035×精神)×(1+0.50h) + 额外每秒法力)
牧师自然法力恢复 = max(0, (3+0.035×min(精神,150)+0.003×max(精神−150,0))×(1+0.50h) + 额外每秒法力)
```

只有明确的全恢复百分比效果才在上述恢复量后乘同组百分比，当前天赋4.0没有默认全恢复倍率。R的一次性回复、技能命中返还、战士普攻产怒不乘急速恢复因子；怒气无自然恢复。战士100上限、开场40、普攻命中+10；盗贼100上限、开场100；法师／牧师100上限、开场100。溢出直接舍弃，不产生补偿资源。

所有技能仍瞬发；急速不缩短独立技能CD、DoT／HoT跳间隔、增益持续、区域持续或天赋内置CD。普通独立CD为`max(基础CD×0.60, 基础CD×(1+同组CD修正))`；消耗为`max(基础消耗×0.50, 基础消耗×(1+同组消耗修正)+平值修正)`。基础0消耗技能保持0，不能因错误的平值修正生成负消耗。节点的“剩余CD减少N秒”是施放后的事件，不改变基础CD下限定义。

计时器保存0至1的普攻进度；频率变化后按新间隔推进未完成进度，不重置、不立即补发。切目标／切阵营共享同一普攻进度，目标无效或满血不补发历史攻击。可执行但无有效治疗的满血友方普攻消耗该次时机、不产生有效治疗计数；无合法目标时计时最多准备一次，不积攒多发。

暂停使用战斗时间dt=0，恢复、CD、持续效果和攻击均不推进。战斗事件在固定步长内按到期时间依次结算；不足资源可以提示但不占GCD。战斗开始所有人普攻进度0，首次普攻需经过一个完整间隔，主动技能CD与GCD为0。同一时间戳先处理到期／周期／自然恢复，再执行玩家命令，命令按接收序号排序；不因帧率不同改变同一输入日志的结果。

## 8 统一事件结算

### 8.1 施放入口

1. 检查场景与输入锁、施法者存活、技能属于当前专精、目标合法、距离及配置要求的遮挡。
2. 读取正式派生属性与当前天赋状态；确定本次使用的形态、消耗、CD与强化。比较预览数据不得进入此处。
3. 检查资源、公共间隔及独立CD。任一失败不付费、不消耗强化、不积累命中／施放计数。
4. 一次性扣费并启动GCD／独立CD，消耗本次强化，生成带稳定cast_id的效果事件；范围对同一目标去重。
5. 逐效果按其类型计算，执行状态变化，最后处理明确的施放／命中后续事件。随机职业归一系数不存在。

### 8.2 伤害管线

```text
B = 技能基础固定值 + 本次k×P                  // 目前32技能固定值默认0
D0 = B × max(0, 1+同组净伤害增量) × (1+m) × q × C
D1 = D0 × M × A
吸收 = min(存活且有效的常规护盾剩余量, D1)
穿盾伤害 = max(0, D1−吸收)
有效生命伤害 = min(目标结算前当前生命, 穿盾伤害)
过量伤害 = max(0, 穿盾伤害−目标结算前当前生命)
```

同组净伤害包含普通增伤、对应技能／条件天赋增减伤、输出端伤害降低；同一来源仅入组一次。例如Q+12%、形态+30%、热力+20%为+62%，不乘1.12×1.30×1.20。技能系数平值变化先改k，不把“+0.50P附加伤害”误写成主命中增伤。

扣护盾后扣生命，生命最低0；目标死亡即标记不可行动并清理其临时状态。以“有效生命伤害”作为战报伤害和赎罪基础，吸收与过量分别统计。命中不要求造成生命伤害：全被盾吸收仍是成功命中，可推进普通命中计数；“承受有效伤害”要求实际掉血大于0，护盾吸收只触发明确的吸收事件。

战报聚合按[掉落、奖励与战报系统设计](掉落奖励与战报系统设计.md)1.0执行：伤害与治疗使用全队战斗区间并集作DPS／HPS分母；主动减伤、实际吸收、有效生命伤害和过量分别守恒归属，护盾到期／替换不算吸收。统计消费本稿实际结算事件，不反向改变战斗量。

### 8.3 治疗与护盾

```text
原始治疗 H = (固定治疗+k×P) × max(0,1+同组治疗增量) × (1+m) × C
有效治疗 = min(H, max(0,最大生命−当前生命))
过量治疗 = max(0,H−有效治疗)
新盾S = (固定盾值+k×P) × max(0,1+同组盾量增量) × (1+m)
```

治疗／盾不乘q、M、穿透或目标主动减伤。m、C是否为1按第4、6节事件资格取值。没有配置的治疗承受修正，不能暗中加到某职业。已死亡目标治疗无效，不复活。

同目标仅一个常规盾池；新S大于旧剩余值才替换并设新持续，否则旧盾与到期时间保持。S=0不生成护盾，不触发“新盾”。新盾量在生成时锁定，之后装备或P变化不重算当前剩余盾。到期／替换／主动移除不算伤害耗尽；护盾耗尽事件每个shield_id仅一次。不同施法者也共用该常规池，来源必须保留用于天赋归属。

### 8.4 戒律的两类附加治疗

基础Q附带治疗固定B=0.60P，只读本牧师P与明确作用于该治疗分支的治疗增量；C=1、m=0，不读取敌人防护或Q有效伤害。Q成功命中时按技能规则寻找受伤友方，不改变当前目标和普攻模式。

赎罪先从Q／敌方E的有效生命伤害乘转换比例，并在每目标0.35P基础上限加微光的上限增量，再乘本牧师适用治疗增量，最后按缺血取有效值；C=1、m=0。多个标记独立治疗，不再防护、不再暴击、不再回流到伤害。赎罪完整目标、持续与延长规则使用天赋4.0。两类治疗独立统计，不能把基础0.60P先加到伤害再转换。

### 8.5 天赋事件的继承类型

所有事件携带root_cast_id、effect_id、来源单位、目标、效果类型和触发深度；技能配置显式区分：

| 类型 | 处理 |
| --- | --- |
| 改变原技能系数或同组加成 | 只修改主事件，不额外结算第二次 |
| 新的固定kP附加伤害／治疗 | 创建独立事件，用自身资格走相应管线，默认无暴击／专精，不再触发附加事件 |
| 按最终直接伤害比例复制（绞肉机） | 取来源命中在护盾之前的D1×复制比例；不重复来源q/C/m/增伤，按次要目标M/A相对主目标M/A的比值修正，再结算次要目标盾与生命；主目标死亡过量不抬高技能基础预算 |
| 按剩余基础持续量结算／复制 | 只取已存基础剩余量，不取已结算伤害；新伤害按目标当前q/M/A与其独立资格结算，详见第9节 |

主目标M×A恒大于0，但实现仍拒绝非法除数。顺劈可等价保存来源D0后乘次要目标M×A，避免反除误差；禁止直接拿主目标掉血量当新目标原始伤害，也禁止再次乘一次源暴击。

按cast_id与节点限制每次触发次数；附加伤害、治疗、资源返还不能默认再触发新一轮同类天赋。只有节点明确的“直接命中”“每第三次普攻”等事件可推进对应状态，天赋额外事件不能伪装新的玩家施放。被消耗／覆盖的强化与局部计数遵守天赋4.0。

## 9 持续效果与快照

本版明确采用**施加时快照输出、结算时读取目标防御**，取代历史实验“所有输出属性逐跳动态读”的方向。对DoT、HoT和区域：施加时锁定P、基础每跳量、来源增伤／治疗增益、来源专精、精准和穿透；命中时读取目标当前回避、护甲／魔抗、减伤、护盾、当前生命。治疗周期读取当前缺血；暴击始终不作用周期。来源增益结束不回溯削减旧周期，重新施加才取新快照。

存储两层数据：`剩余基础量`只含施加时固定值+kP，不含q、暴击、专精、增伤和目标防护；`输出快照`单独存修正。毒性爆发／点燃复制只读前者，不能把已经乘过增益的伤害再次乘。滚动点燃、形态改变跳数、3P上限和刷新保留跳钟使用天赋4.0；“3P上限”读取本次新施加快照的P。

按剩余基础量创建的新附加事件，取**触发时**的新输出快照，但不重新把该基础量乘一次P；其精准／穿透用触发者当时值。蔓延点燃副本默认无专精资格，复制量只进一次新的三跳总预算；旧目标已发生的跳伤不复制。

同施法者同节点同目标默认一份持续效果，重施刷新而非并存。无明确例外时重置跳钟，首次2秒后；不同施法者分别记录。区域同施法者同节点最多一个，固定施放位置，替换不补跳。持续末端恰好到期的最后一跳先结算再过期；护盾／增益在其到期时刻先过期，再处理同刻新伤害，不能多挡一击。

效果来源死亡或战斗结束时清除其持续伤害、治疗、区域与天赋状态；已生成的常规盾保留至过期／耗尽（死亡目标自身盾立即清除），赎罪来源死亡按天赋规则清除。清除不是伤害耗尽。这个生命周期规则需所有敌我效果统一执行。

## 10 防御、仇恨及控制接口

仇恨采用公开基础：普通专精伤害仇恨=有效生命伤害×1；守护=有效生命伤害×3；盾击再乘技能自身2倍仇恨系数及其显式修正。有效治疗仇恨=有效治疗×0.20，均分到本场仍存活、已激活且与被治疗者处于战斗的敌人；无符合敌人不生成。护盾生成、过量治疗、资源恢复不产仇恨，吸收量只做统计、不额外产仇恨。

当前目标有效时，挑战者仇恨严格大于当前目标1.10倍才切换；相等保留当前目标。当前目标失效时按最高仇恨，平手按稳定单位ID排序；尚无仇恨时由遭遇AI的接敌规则指定初始目标。嘲讽成功时自身仇恨升至max(自身仇恨,当前最高×1.10)，并强制目标按技能时长攻击；结束再比较。重叠嘲讽以最后成功生效来源为准，旧嘲讽不在新效果结束后自动恢复。

仇恨只决定正常AI选目标，不改变独立技能明确的随机／最低血目标机制；具体接敌、选目标、技能锁定与阶段行为见[敌人与Boss系统设计](敌人与Boss系统设计.md)1.0。嘲讽不能让死亡单位攻击，本稿数值公式继续作为唯一仇恨基线。

本版控制只有既定打断与减速：可打断施法取消，不叠加沉默；减速取最强，首领幅度×0.5、持续不变。控制抗性评级、韧性、控制疲劳、硬冻结、击退及主动格挡／招架窗口暂不加入。减速不影响普攻间隔或技能CD，移动速度最低基础25%；不把减速当急速减少。

## 11 面板、预览与保存

角色面板展示L、五属性、P、最大生命、护甲／魔抗及对应无穿透减伤率、精准／回避评级、暴击收益参数与稳定增幅、急速、专精收益及作用技能、穿透、实际普攻间隔、资源上限与每秒自然恢复。命中质量与有效防护依赖目标，仅在目标详情／比较上下文展示，不伪造固定“实际伤害”。

换装预览用同一函数从基础重算，仅替换候选槽位；装备、天赋同参数来源需可追溯。预览不改变生命、资源、盾、持续快照、冷却或已保存状态。关闭预览即丢弃派生副本。

存档保存等级、基础配置ID、装备实例、专精和天赋方案及必要进度；不把P、最大生命、技能最终倍率保存为权威输入。配点保存与战斗状态恢复分别按存档系统处理。新公式标识combat_stats_v1_1，不与天赋树数据version=4混为一个版本号；旧档不得因为天赋编号相同就直接套用旧派生属性。

## 12 可复算样例与验收

### 12.1 伤害与吸收

固定测试输入（不是60级推荐装备）：P=500，Q倍率1.20，同组增伤+20%，适用专精m=0.20，精准／目标回避均0，暴击评级0所以C=1.025；目标护甲1000，穿透评级1000所以F=825；目标减伤30%，护盾100，生命2000。

```text
B=600
D0=600×1.20×1.20×1×1.025=885.6
D1=885.6×1000/1825×0.70≈339.68219178
吸收=100；有效生命伤害≈239.68219178；目标剩余生命≈1760.31780822
```

### 12.2 治疗、护盾和赎罪

P=500，Q治疗2.40P，同组治疗+10%，适用m=0.20，暴击评级0：H=1200×1.10×1.20×1.025=1623.6。缺血700则有效700、过量923.6。

W基础盾2P=1000，盾量+10%、适用m=0.20得到1320，不能再乘1.025。旧盾剩余1400则不替换；旧盾剩余800则替换为1320并重新设持续。

赎罪2阶转换24%，本次有效生命伤害1000、P=500、未学微光：先得240，单目标上限175，治疗增益+10%后192.5，再按缺血截断。不会再乘暴击或专精。基础Q固定治疗另算0.60×500=300，未有分支治疗增益时仍为300。

### 12.3 时间与资源

急速评级1000，h=0.15。基础2秒普攻在无其他增益时为2/1.15≈1.73913秒；再有30%普攻频率增益则2/1.45≈1.37931秒。GCD=1/1.15≈0.86957秒，基础8秒技能仍8秒。

盗贼恢复8×1.075=8.6/秒；精神100的法师或牧师恢复(3+3.5)×1.075=6.9875/秒；精神361、急速评级300的牧师按新曲线恢复约9.1905/秒；战士每次普攻仍+10怒气。2秒持续跳伤依旧2秒，不因急速多跳。

### 12.4 必测边界

- 四职业1／30／60级按表复算；重复重算、反复换装／切专精不累积属性。
- 所有评级0、1000、极大合法值；q／c／h／p单调且不越范围；非法数拒绝。
- 物理／魔法只读对应防护；穿透不使防护为负；治疗／盾不吃精准与敌方防护。
- 八专精逐标签验证m；来源复制不重复乘C／m；持续无暴击；Q固定治疗与赎罪分开。
- 先减伤后护盾再生命；致死伤害、全吸收、过量、护盾到期／替换／耗尽分别验证。
- 友方／敌方普攻共享计时；切目标、加急速、暂停／恢复、满血等待不能补发多次。
- 快照后来源增益到期、目标防御变化、同刻最后一跳与过期行为可复现。
- 同一输入日志在30／60／120渲染帧率下，固定战斗步长结果一致；不存在多目标重复返还。
- 从无装备到初始八槽、单人到四人、首领到群怪分别记录DPS、有效HPS、护盾吸收、资源溢出／空转、承伤与仇恨转移。

本稿的可复算样例可用于规则单测，但不代替战斗平衡实验。特别关注高精神法力恢复、治疗专精单人通关效率、守护群怪仇恨、点燃滚存与顺劈覆盖。未完成这些测试前，不宣称职业强度或装备收益已平衡。
