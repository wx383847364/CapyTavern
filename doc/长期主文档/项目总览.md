- 玩法定位：待定，由制作人、策划补全

- 当前阶段：空仓起步

- 当前建议起点：酒馆制作人（拆单、契约、验收）

## 当前稳定结论

- git 单仓；各路径唯一写者见 [目录与写权边界](架构与边界/目录与写权边界.md)。
- 客户端引擎 Godot / Unity 尚未定案；定案前不落引擎专属目录，不提交生成物。
- 任何人不自行 commit，只 prepare；human 明确说「提交」才 commit。
- 提交标题固定为 `[TMMSSSSS] 类型：摘要`，细则见 [Git 提交与确认规则](协作与执行/Git%20提交与确认规则.md)。
- `locks.md`、`dispatch.md` 是运行态，不进 git。
- 生成物、导出物、构建产物不进 git。
- `tools/doc_maintenance/**`、`tools/repo_maintenance/**`、`.githooks/**` 归制作人；整棵 `tools/**` 不预支给单一岗位。
- 表现岗定名为「酒馆表现」，评审并入制作人。
